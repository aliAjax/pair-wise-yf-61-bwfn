# 远程设备固件分批发布控制台

源提示词摘要：发布负责人选择设备范围、固件版本、分批比例和回滚版本，运维设定兼容条件与失败阈值，值班人员监视下载、安装、重启和异常事件；关键发布支持审批、暂停、继续和紧急回滚，过期状态不可误用。

## 技术栈

Angular、TypeScript、Angular Material、NgRx、Angular Router、RxJS、Angular CDK、Transloco。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62026`

## 可用流程

- 创建发布批次并关联设备分组、固件版本、分批比例和失败阈值；分组内混装的每个型号都实时显示。
- 审批前按分组里的**每个型号**逐个对照固件仓库升级清单：目标版本不在升级清单（升不上去）或回滚版本不在可回退清单（退不回来）一律驳回，并在审计与面板上列出全部不合格型号及原因。
- 批次从草稿、已审批、发布中、暂停到完成或回滚；兼容条件阻止不合格分组加入发布；实时指标由本地遥测模拟驱动。
- 固件仓库清单换版（rev4/rev5 演示按钮）后，进行中的批次对未下发设备立即按新清单重算并拦截，已经装上目标版本的设备照原版本走完、单独计入“待回退”。
- 紧急回滚按当前清单逐型号校验：退不回来的型号不计为已回退，批次置为“回退失败（待补偿）”，并生成补偿记录，可在清单恢复后重试或登记人工闭环；全部补偿闭环后批次才转为已回退。
- 审批、暂停、继续、回滚、清单换版和补偿处置均保留审计记录并持久化到 localStorage（键名 `firmware-release-v2`，旧结构会被安全丢弃）。
